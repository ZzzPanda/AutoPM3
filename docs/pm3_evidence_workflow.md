# PM3 Evidence Extraction Workflow

本文档总结组内获取 PM3 证据结论的 4 个核心步骤，用于文献检索、病例证据抽取和人工复核。

## 核心步骤概览

| 步骤 | 关键动作 | 目的 | 关键产出 |
| ---- | ---- | ---- | ---- |
| 1. 文献筛选 | 过滤健康人筛查、非目标疾病（如癌症）及无关文献 | 排除无效数据，聚焦目标疾病患者 | 候选文献清单 |
| 2. 信息提取 | 从摘要、正文或附录表格中提取患者数量、表型、基因型（纯合/复合杂合）及反式位点 | 获取支持 PM3 的具体病例证据 | 结构化病例证据表 |
| 3. 数据去重 | 比对作者、单位、年龄及变异组合，识别并剔除重复报道的同一病例 | 确保证据独立性，避免重复计分 | 独立病例列表 |
| 4. 人工算分 | 根据先证者数量及证据强度（如是否有家系验证）手动计算分值 | 确定 PM3 证据等级（如 Supporting、Moderate、Strong） | PM3 评分与证据等级 |

## 1. 文献筛选

目标是先做减法，只保留可能提供 PM3 病例证据的文献。

优先保留：

- 目标疾病患者队列或病例报道。
- 明确提及目标基因、目标变异或等价 HGVS 表达的文献。
- 包含患者基因型、家系检测、附录表格或病例级信息的文献。

优先排除：

- 健康人筛查、携带者频率或一般人群数据库文献。
- 非目标疾病队列，例如癌症研究中偶然提及该基因或变异。
- 只讨论功能、结构或机制，但没有患者病例和基因型的文献。
- 无法定位到目标变异或等价命名的文献。

## 2. 信息提取

从候选文献中提取能支持 PM3 的病例级信息。PM3 的核心不是“找到变异”，而是确认患者是否满足：

- 隐性疾病背景。
- 患者中存在待评估变异。
- 位点状态明确，例如纯合、复合杂合、反式或顺式。

建议抽取字段：

- PMID、标题、作者。
- 患者数、家系关系、年龄或其他可去重信息。
- 疾病名称和临床表型。
- 待评估变异。
- 另一等位基因变异。
- 是否纯合或复合杂合。
- 反式位点及确认方式，例如父母检测、家系检测或其他相位证据。
- 顺式位点，如果存在复合等位基因。
- 作者对该基因型是否解释疾病的结论。

关键要求：

- 复合杂合病例必须明确具体反式位点，否则不能作为有效 PM3 证据。
- 仅采纳作者明确认定该位点或等位基因与疾病相关的病例。
- 如果作者仅表示“怀疑”“不确定”或认为可能由其他位点解释，应谨慎处理或不纳入计分。

## 3. 数据去重

同一病例可能在不同文章、补充材料、队列更新或二次分析中重复出现。计分前必须确认病例独立性。

去重线索：

- 作者、研究单位或合作团队是否高度重叠。
- 患者年龄、性别、家系关系是否一致。
- 目标变异与反式变异组合是否一致。
- 疾病表型和临床描述是否高度相似。
- 文献是否明确说明来自同一队列、同一家系或前序研究。

处理原则：

- 同一病例只能计分一次。
- 无法确认是否重复时，应标记为需人工复核，不应自动重复计分。
- 去重判断应保留依据，方便后续复查。

## 4. 人工算分

PM3 评分需要人工结合病例数量和证据强度判断，不能只按文献命中数计算。

算分前检查：

- 是否为独立受累先证者或独立病例。
- 是否明确纯合、复合杂合或反式状态。
- 另一等位基因是否为致病或可能致病变异。
- 是否有家系验证、父母检测或其他相位证据。
- 作者是否明确认为该病例由相关变异解释。

输出时应给出：

- 纳入计分的病例数。
- 排除病例及原因。
- 每类证据的计分依据。
- 最终 PM3 证据等级，例如 Supporting、Moderate 或 Strong。
- 支撑 PMID 和关键病例描述。

## 标准化结论

```text
该变异已在[至少]XX名患有[疾病/表型]的个体中被检测到。
其中XX名为该变异与一个致病性或可能致病性变异[具体位点]的复合杂合，
其中XX名通过[父母/家庭检测/其他方法]确认处于反式位置。
XX名个体为该变异纯合。[PMID:xxxxx]
```

## 快速核对清单

- 目标变异 HGVS、蛋白表达和坐标是否一致。
- 文献是否来自目标疾病患者，而不是健康筛查或无关疾病队列。
- 是否抽取了患者数、表型和完整基因型。
- 复合杂合病例是否明确具体反式位点。
- 重复病例是否已剔除。
- 作者是否明确认为该位点或等位基因解释病例。
