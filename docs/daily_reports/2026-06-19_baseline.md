## 2. Main Code Changes

### Markdown-aware evidence chunking

- Added `app/core/markdown_splitter.py`.
- Introduces a Markdown-aware splitter that preserves HTML tables, pipe tables, fenced blocks, images, and heading metadata.
- Adds metadata such as `chunk_kind`, `source_heading`, `contains_table`, and `block_count`.
- Intended to replace plain recursive character splitting where table rows and variant evidence could be split apart.

### Variant retrieval diagnostics and isolation

- `VariantSpecificRetriever` now receives per-instance diagnostics instead of relying on shared module-level state.
- Mutalyzer protein normalization is factored into helper functions.
- Protein search forms now include long and short forms, with terminal symbols normalized.
- Diagnostic output now records input HGVS, DNA search regex, protein search forms, match counts, and fallback behavior.

### PM3 evidence workflow

- Added a new Streamlit page: `app/pages/4_PM3_Evidence_Workflow.py`.
- Added prompt rendering helpers:
  - `render_pm3_evidence_workflow`
  - `render_chinese_translation`
- Added workflow-oriented prompts:
  - `app/prompts/pm3_evidence_workflow.j2`
  - `app/prompts/translate_to_chinese.j2`
- Added `docs/pm3_evidence_workflow.md`, documenting the four-step PM3 evidence extraction process:
  - literature screening
  - information extraction
  - deduplication
  - manual scoring

### Evidence-linked rendering improvements

- `render_result` now accepts a custom `section_body_renderer`.
- Evidence result UI now supports linked source chunks and linked sections.
- Standardized conclusion blocks can be rendered with a distinct blue callout style.
- PM3 workflow page supports per-block Chinese translation with session-level caching.

### Test and packaging setup

- Added `pyproject.toml`.
- Added unit and integration tests for Markdown splitting and retriever behavior.
- Added fixtures for PubMed/BioC/Markdown-based tests.
